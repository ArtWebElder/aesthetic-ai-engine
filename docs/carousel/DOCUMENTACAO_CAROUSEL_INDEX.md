## 🎬 EXEMPLO REAL: Carousel Product 360

```
USER FLOW:

2. Seleciona: Preset "Drama" + Tipo "Product 360" + 6 slides
3. Clica "Run"
4. Sistema processa:
   ├─ Preprocess subject 1x
   ├─ Loop 6x (Gemini img2img com prompts diferentes)
   │  ├─ Slide 1: Frontal view
   │  ├─ Slide 2: Side angle 45°
   │  ├─ Slide 3: Close-up detail
   │  ├─ Slide 4: Elevated angle
   │  ├─ Slide 5: Low angle dramatic
   │  └─ Slide 6: Lifestyle context
   ├─ Color grade global (unificar paleta)
   └─ Preview gallery (6 thumbnails)
5. Adiciona textos ("Novo Produto 2024" em todos)
6. Exporta 6 imagens PNG (1080x1920)
7. Publica no Instagram Carousel ✓

RESULTADO: 6 imagens profissionais, pronto para ir viral!
```
